# 🐱 CatHouse (Котодім)

Адаптивна односторінкова верстка (лендинг/блог) про котів: підбірка постів, лонгрід-блог зі статтями, соцмережі та відеоблок. **Уся верстка побудована виключно на CSS Grid** — жодного flexbox чи `float` немає в жодному з компонентів; кожен блок сторінки, від хедера до футера, це окрема grid-контейнер.

## 🧱 CSS Grid — основа всієї верстки

Це головна технічна особливість проєкту: замість комбінування flexbox і grid, тут послідовно застосовано **тільки Grid**, у тому числі там, де flexbox напрошується сам (наприклад, для рядка "іконка + текст" у хедері чи футері). Ключові приклади:

- **`.header-container` / `.footer-container`** — `grid-template-columns: 24px 1fr`: іконка лога фіксованої ширини + назва, що розтягується.
- **`.posts`** — стрічка постів через `grid-template-columns`, з `repeat(2, 1fr)` на планшеті+; перший пост займає одразу дві клітинки через `grid-column`/`grid-row` (`1 / 2` та `1 / 3`) — класичний прийом "featured card" на Grid.
- **`.longread`** — найяскравіший приклад: на десктопі (≥1440px) розкладка блогу, соцмереж і відео задається іменованими ділянками:
  ```css
  grid-template-areas:
    "b b s"
    "b b s"
    "b b v"
    "b b .";
  ```
  де `b` (blog), `s` (socials) і `v` (video) — самостійні grid-area, що дозволяє змінювати їх порядок і розмір без переписування розмітки HTML.
- **`.blog-link`** — кожна картка статті сама є grid-контейнером (`264px 1fr`) для пари "фото + текст".
- **`.socials-list`** та **`.social-link`** — вкладені grid-и: список іконок соцмереж (`repeat(2, 1fr)`) і кожна іконка з підписом усередині (`32px 1fr`).

## ✨ Що є на сторінці

- **Header** з логотипом і назвою сайту.
- **Стрічка постів** (`posts`) — 3 картки з фоновим зображенням і заголовком-оверлеєм; перша картка використовує `<picture>` з `srcset` для окремих зображень під мобільні та десктопні екрани.
- **Блог-лонгрід** (`blog`) — 4 картки статей із фото, заголовком і описом.
- **Соцмережі** — список іконок (Instagram, Facebook, YouTube, TikTok, GitHub, Twitter) із кількістю підписників.
- **Відеоблок** — банер із превью відео.
- **Footer** з логотипом.

## 🛠 Технологічний стек

- **HTML5** — семантична розмітка (`header`, `main`, `section`, `footer`)
- **CSS3 Grid** — уся розкладка сторінки, включно з вкладеними та іменованими сітками (`grid-template-areas`)
- **CSS custom properties** — дизайн-токени (кольори, шрифт) у `styleguide.css`
- **Google Fonts** — шрифт [Montserrat](https://fonts.google.com/specimen/Montserrat) (400, 700)
- Без збірників, без залежностей — чистий статичний сайт

## 🎨 Дизайн-система

Кольори та типографіка винесені в CSS-змінні в `styleguide.css`:

| Змінна                                                                                | Значення                            | Призначення                |
| ------------------------------------------------------------------------------------- | ----------------------------------- | -------------------------- |
| `--common-white`                                                                      | `#fff`                              | базовий білий              |
| `--orange`                                                                            | `#f07f2e`                           | акцентний колір            |
| `--grey` / `--common-black`                                                           | `#2c2c2c` / `#2f2f37`               | текст                      |
| `--blue-light`, `--navy`, `--scarlet`, `--yellow`, `--pink`, `--turquoise`, `--lilac` | пастельна палітра                   | фони карток блогу/соцмереж |
| `--common-font`                                                                       | `Montserrat, Helvetica, sans-serif` | основний шрифт             |

Типографічні класи `.title` (28px/700) та `.sub-title` (16px/700, 20px/700 з 768px) використовуються для заголовків по всій сторінці.

## 📱 Адаптивність

Верстка адаптивна, брейкпоінти: **320px+** (мобільна база), **768px** (планшет) та **1440px** (десктоп). На кожному брейкпоінті змінюється саме конфігурація grid-контейнера — кількість колонок (`grid-template-columns`), gap або повна переорганізація через `grid-template-areas` (секція `.longread`), а не додаткові обгортки чи flex-хаки.

Перша картка стрічки постів додатково використовує `<picture>` з двома джерелами (`picture-1.png` для ≥768px, `picture-1-small.png` для 320–767px), щоб не віддавати важке зображення на мобільні пристрої.

## 🚀 Запуск проєкту

Проєкт не потребує збірки — достатньо відкрити `index.html` у браузері, або підняти локальний сервер (рекомендовано, щоб уникнути проблем з відносними шляхами):

```bash
git clone https://github.com/Anna-Ivanchenko/CatHouse.git
cd CatHouse
```

Далі — будь-яким зручним способом:

- розширення **Live Server** у VS Code (клік правою кнопкою на `index.html` → "Open with Live Server");
- або `npx serve .`;
- або просто відкрити `index.html` подвійним кліком.
